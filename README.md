# ACLib DBMS Connection Wizard
Configure DBMS connection + import DBMS connection framework

More information and video: https://www.access-codelib.net/en/tools/dbms-connection-wizard

## Install
1. Download the zip file from the [latest release](https://github.com/AccessCodeLib/DbmsConnectionWizard/releases/latest) and extract `DbmsConnectionWizard.accda`.
2. Open `DbmsConnectionWizard.accda` in Access.
3. Click "Install Add-in" in the install form.

Note:
Use "Install Add-in as accde" to install a compiled version.
